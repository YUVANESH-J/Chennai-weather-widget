
# 🌤 Chennai Weather + Power Cut Prediction

A simple web application that shows live weather data of Chennai and predicts possible power cut risk based on weather conditions.

---

## 🚀 Live Demo
🔗 https://yuvanesh-j.github.io/Chennai-weather-widget/

---

## 📌 Problem Statement
Chennai often experiences power cuts during extreme weather conditions like heavy rain, strong winds, or high temperature load.  
There is no simple tool to quickly estimate possible power disruption risk.

---

## 💡 Solution
This project fetches real-time Chennai weather data using OpenWeather API and applies rule-based logic to predict power cut risk.

---

## ⚙️ How It Works
1. Fetch live weather data from OpenWeather API.
2. Extract:
   - Temperature
   - Wind Speed
   - Weather Condition
3. Apply prediction rules:
   - 🌡 Temperature > 40°C → Medium Risk
   - 🌧 Rain → High Risk
   - 💨 High Wind Speed → High Risk
   - Normal conditions → Low Risk
4. Display result dynamically on webpage.
